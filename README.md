# 🏠 House Price Prediction

A machine learning web application built with Python and Streamlit to predict house prices based on different house attributes.

## 📌 Project Overview

This project uses a Linear Regression model to predict house prices based on features such as:

- Area
- Number of bedrooms
- Number of bathrooms
- Number of stories
- Parking
- Main road access
- Guest room
- Basement
- Hot water heating
- Air conditioning
- Preferred area
- Furnishing status

## 🛠️ Technologies Used

- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib
- Streamlit

## 🤖 Machine Learning

The dataset was preprocessed by converting categorical features into numerical values.

The data was then divided into training and testing sets and a Linear Regression model was trained.

### Model Performance

- **R² Score:** 0.7331
- **Mean Absolute Error:** approximately 697,326
